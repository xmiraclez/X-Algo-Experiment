# Пилот эксперимента «30 дней с алгоритмом X»

Локальная страница, которая каждый день говорит, что сделать: текст поста, картинку, когда отвечать и какие цифры записать. Данные лежат на вашем компьютере. Отдельные программы ставить не нужно: хватает Python 3, он уже есть в Debian 13.

Папка программы: `pilot/`.

## Запуск на Debian 13 (amd64)

Откройте терминал в папке `pilot`.

```sh
python3 --version
timedatectl
```

`python3` должен показать 3.x. Если команды нет: `sudo apt install python3`.

`timedatectl` должен показывать `Time zone: Europe/Moscow`. Помощник берёт время из браузера, а браузер берёт его из системы. Если зона другая, «21:00» в помощнике не совпадёт с московским вечером вашей аудитории.

Запуск:

```sh
python3 server.py
```

В терминале появится строка `Пилот эксперимента: http://127.0.0.1:5055`. Откройте её в Firefox или Chromium. Терминал не закрывайте: пока он открыт, страница работает. Остановка — `Ctrl+C`. Данные при этом не стираются. На следующий день снова `python3 server.py` из той же папки.

Если порт занят:

```sh
python3 server.py --port 5056
```

и откройте `http://127.0.0.1:5056`.

## Первые десять минут

1. Нажмите «Начать новый эксперимент».
2. Запишите код вида `ABCD-EFGH-JKLM` на бумаге. Он же имя файла в `pilot/data/`.
3. Ник и число подписчиков.
4. Просмотры 10–15 последних обычных постов: не ответы и не репосты. Один вирусный пост в этом списке раздувает разброс, и помощник честно скажет, что заметит только сильный эффект. Такой пост в список не кладите.
5. Время публикации, когда вы ещё полчаса у телефона. В половине дней нужно ответить сразу.
6. День старта. Анонс в этот день, первый пост серии — на следующий.

Дальше вкладка «Сегодня». Делайте то, что в блоке «Сделать сейчас», сверху вниз.

## Каждый день серии

- Откройте `http://127.0.0.1:5055`. Если браузер уже запомнил эксперимент, мастер снова не спрашивает. Иначе введите код.
- Опубликуйте текст как есть, без ссылок, хештегов и просьб лайкнуть. Картинку прикрепляйте только когда помощник её дал.
- Перед публикацией откройте источник факта дня и убедитесь, что формулировка ещё верна. Код X меняется, константы тоже.
- За 2 часа до поста серии и 2 часа после других постов нет.
- В дни «отвечать сразу» отвечайте в первые 30 минут. В дни «через 3 часа» до этого срока комментарии не трогайте.
- Через сутки внесите просмотры, лайки и ответы. Следующий пост серии без этой цифры не откроется.
- Блок «Дописать, когда будет минута» — просмотры за 48 часов и за 7 дней. Сегодняшний пост они не блокируют, но к итогам их лучше внести.
- Условия будущих дней на вкладке «Дни» скрыты. Не показывайте экран «Сегодня» зрителям: на нём видно условие текущего дня.

## Раз в неделю

Настройки → «Скачать копию (JSON)». Храните файл отдельно от компьютера. Папка `pilot/data/` — это и есть вся память эксперимента. Её имеет смысл копировать вместе с JSON.

В воскресной сводке помощник попросит просмотры трёх обычных постов и метки Under the Hood. Это проверка, не вредит ли серия аккаунту. Если он скажет поставить паузу — поставьте.

## Финал

Помощник сам напишет тред с интервалами. Это t-тест логарифма просмотров за 24 часа, не перестановочный тест из первоначального плана. В тексте уже есть интервал. Его и цитируйте. Если пост сильно выбился из ряда, в заметке дня напишите об этом и в итоговом треде скажите, что цифра посчитана вместе с этим днём.

Расписание откроется в треде. Хеш из анонса должен совпасть. Помощник пишет, совпал ли он.

## Телефон в домашней сети

По умолчанию страница доступна только с этого компьютера. Чтобы открыть её с телефона в той же Wi-Fi сети:

```sh
python3 server.py --host 0.0.0.0
```

На телефоне откройте `http://АДРЕС-КОМПЬЮТЕРА:5055`. Адрес смотрите командой `hostname -I`. Код эксперимента в этом режиме — пароль. Порт в интернет не пробрасывайте. Когда телефон не нужен, запускайте сервер снова без `--host`.

## Чтобы не держать терминал открытым

Один раз, подставив полный путь к папке `pilot` (команда `pwd`, когда вы уже в ней):

```sh
mkdir -p ~/.config/systemd/user
cat > ~/.config/systemd/user/x-pilot.service << EOF
[Unit]
Description=Пилот эксперимента с алгоритмом X

[Service]
WorkingDirectory=/ПОЛНЫЙ/ПУТЬ/pilot
ExecStart=/usr/bin/python3 -u /ПОЛНЫЙ/ПУТЬ/pilot/server.py
Restart=on-failure

[Install]
WantedBy=default.target
EOF
systemctl --user daemon-reload
systemctl --user enable --now x-pilot.service
```

Проверка: `systemctl --user status x-pilot.service`. Логи: `journalctl --user -u x-pilot.service -n 50`. Остановка: `systemctl --user stop x-pilot.service`.

Так страница поднимается вместе со входом в систему. Чтобы она жила и без входа, один раз: `sudo loginctl enable-linger "$USER"`.

## Если что-то пошло не так

- «Сервер не ответил» — терминал с `python3 server.py` закрыт или открыт не тот адрес.
- Забыли код — посмотрите имена файлов в `pilot/data/`. Код — это имя файла без `.json`. Файл `sessions.json` не код.
- Другой браузер на этом компьютере: «У меня есть код».
- Начать заново можно в настройках. Сначала скачайте копию: стирание необратимо.
